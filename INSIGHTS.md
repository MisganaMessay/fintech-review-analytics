# Business Insights and Recommendations

## Commercial Bank of Ethiopia (CBE)

### Satisfaction Drivers
- Fast transaction processing
- Easy money transfer
- Reliable mobile banking experience

### Pain Points
- Occasional update-related issues
- Some login delays

### Supporting Evidence
CBE achieved the highest positive sentiment score (67.6%) and the highest average rating (4.122). Common positive keywords included:
- fast
- excellent
- easy
- transaction

### Recommendations
1. Continue optimizing transaction reliability and speed.
2. Improve testing before app updates to reduce technical issues.

---

## Bank of Abyssinia (BOA)

### Satisfaction Drivers
- Convenient banking services
- Useful mobile banking features

### Pain Points
- Slow performance
- Failed transactions
- App crashes

### Supporting Evidence
BOA had the highest negative sentiment percentage (47.2%) and the lowest average rating (3.566). Common negative keywords included:
- slow
- problem
- worst
- doesn't work

### Recommendations
1. Improve backend infrastructure and app performance.
2. Add stronger error handling and bug-fixing processes.

---

## Dashen Bank

### Satisfaction Drivers
- User-friendly interface
- Fast account access
- Easy navigation

### Pain Points
- App freezing after updates
- Some login inconsistency

### Supporting Evidence
Dashen achieved strong positive sentiment (64.2%). Frequently appearing keywords included:
- friendly
- easy
- super
- fast

### Recommendations
1. Continue improving usability and customer experience.
2. Improve app stability after new updates.
